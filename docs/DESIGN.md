# 화면 구성

PBL 중간발표 보고서의 운전자 화면을 기준으로 구성했다.

- 상단: 시스템 이름, 선택 노선·방향, 갱신 상태, 기기 시각
- 왼쪽: 현재 정류장과 다음 정류장
- 오른쪽: 승차 대기(파랑), 하차 요청(빨강)
- 하단: 현재 위치 주변 정류장 연결선

Kotlin과 XML을 사용한다. `activity_main.xml`에서 카드와 텍스트를 배치하고 `RouteTimeline`에서 노선도를 그린다. 가로 태블릿 화면에 맞춰 글자와 여백 크기를 조정한다.

## 조작

- 제목: 노선 재선택 및 서버 설정
- 노선·정류장 카드: 운행 시작, 다음 정류장, 종료
- 갱신 상태: 정류장별 예약 상세 및 재조회

현재 정류장은 수동으로 이동한다. 도착 예상 시간과 GPS 자동 진행은 구현하지 않았다.
